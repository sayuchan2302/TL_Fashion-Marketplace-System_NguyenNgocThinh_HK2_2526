# UI Screenshot Checklist for Chapter 4

## Quy tắc chụp ảnh UI

- Chụp màn hình ở độ phân giải rõ, ưu tiên 1366x768 hoặc 1920x1080.
- Ẩn dữ liệu nhạy cảm như email thật, số điện thoại thật, secret hoặc token.
- Đặt tên file không dấu, dễ hiểu.
- Khi chèn vào Word: canh giữa, rộng khoảng 14-15.5 cm; dashboard rộng có thể crop hoặc dùng trang ngang.
- Mỗi ảnh có caption dưới ảnh dạng `Hình 4.x: ...`.
