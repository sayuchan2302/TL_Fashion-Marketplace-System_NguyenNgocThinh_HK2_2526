# SRS Update Instructions

## Sau khi chèn ảnh UI

1. Mở `SRS_upgraded_no_UI.docx` bằng Microsoft Word.
2. Tìm các dòng `[Chèn ảnh UI tại đây]` trong Chương 4.
3. Thay từng placeholder bằng ảnh UI thật.
4. Chọn ảnh, đặt kích thước phù hợp:
   - Ảnh thường: rộng khoảng 14-15.5 cm.
   - Dashboard rộng: crop phần quan trọng hoặc dùng trang ngang nếu cần.
5. Giữ caption dưới ảnh theo đúng thứ tự `Hình 4.x`.

## Cập nhật mục lục và danh mục

Vì file SRS hiện có danh mục/mục lục dạng văn bản tĩnh hoặc cần Word cập nhật lại sau khi chèn ảnh, hãy thực hiện:

1. Nhấn `Ctrl + A`.
2. Nhấn `F9`.
3. Nếu Word hỏi, chọn `Update entire table`.
4. Kiểm tra lại:
   - Mục lục.
   - Danh mục hình ảnh.
   - Danh mục bảng.
   - Số trang.

Nếu danh mục hình/bảng đang là văn bản tĩnh, cần thêm thủ công các mục mới:

- Hình 4.1 đến Hình 4.19.
- Bảng 3.26: Yêu cầu phi chức năng của hệ thống.
- Bảng 3.27: Đối chiếu chức năng, giao diện, API/module và dữ liệu.
- Bảng 3.28: Các vấn đề gặp phải và giải pháp giải quyết.

## Kiểm tra layout trước khi nộp

- Không để ảnh bị mờ hoặc chữ UI quá nhỏ.
- Không để bảng bị tràn lề.
- Không để caption nằm tách trang khỏi ảnh.
- Kiểm tra page number ở giữa dưới.
- Kiểm tra font Times New Roman và normal 13pt.
- Kiểm tra line spacing 1.3-1.5.
- Kiểm tra lề: trên/dưới 2.7 cm, trái 3.4 cm, phải 2 cm.

## Kiểm tra cuối cùng

- Xuất PDF từ Word.
- Xem toàn bộ PDF từ đầu đến cuối.
- Đặc biệt kiểm tra các trang có bảng mapping, bảng vấn đề, Chương 4 và ảnh UI.
